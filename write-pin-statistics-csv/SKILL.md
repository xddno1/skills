# 引脚统计 CSV 输出规范

## 输出字段

CSV 文件必须包含以下列：

| 列名 | 说明 |
|------|------|
| 引脚编号 | 芯片引脚编号（如 PA0、PB5 等） |
| 引脚功能及其复用功能 | 该引脚支持的所有功能（GPIO、UART、SPI、I2C、ADC 等） |
| 实际配置功能 | 当前项目中实际配置的功能 |
| 引脚方向 | 输入 / 输出，以及具体类型（推挽输出、开漏输出、上拉输入、浮空输入、模拟输入 等） |
| 所属模块 | 该引脚归属的功能模块（如 LCD、按键、传感器、通信接口 等） |
| 代码配置位置 | 驱动层配置该引脚的代码位置（文件路径和函数名，不要太靠应用层） |
| 备注信息 | 特殊说明（电平要求、上下拉、速度等级、复用配置 等） |

## 输出要求

1. 文件保存到工程的 `.ai-output/` 目录下
2. 文件名为 `pin_statistics.csv`
3. 编码使用 UTF-8 BOM（保证 Excel 打开中文不乱码）
4. 写入前需回到项目代码中**逐一验证**每个引脚的配置，不能靠猜测
5. 如有不确定项，在"备注"列标注，不要编造
