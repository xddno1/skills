# 获取当前电脑时间

通过 PowerShell 的 `Get-Date` 命令读取本机系统时间，并将结果以中文清晰呈现给用户。

## 步骤

1. 使用 PowerShell 工具运行下面的命令，一次性拿到完整信息：

   ```powershell
   Get-Date -Format "yyyy-MM-dd HH:mm:ss dddd zzz"
   ```

   该格式输出：日期、24 小时制时间、星期、UTC 偏移（时区）。

2. 把结果直接展示给用户，例如：

   > 当前电脑时间：2026-05-07 14:50:32 星期四 (UTC+08:00)

3. 如果用户只问其中一部分（如"今天星期几"），只回答相关字段，不要堆砌全部内容。

## 注意

- 始终读取**本机**时间，不要使用网络/记忆中的日期。
- Windows 中文系统下星期会显示为"星期四"等中文，无需额外翻译。
- 不要使用 `date` 这个 Bash 命令——本环境是 Windows，应统一用 PowerShell 的 `Get-Date`。
