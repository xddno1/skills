# 按键统计 CSV 输出规范

## 输出字段

CSV 文件必须包含以下列：

| 列名 | 说明 |
|------|------|
| 有效页面/状态 | 该按键生效的页面或系统状态 |
| 按键/组合 | 按键名称或组合键（如 "POWER"、"UP+DOWN"） |
| 触发方式 | 触发类型：短按 / 长按 / 双击 / 连击 / 上电触发 等 |
| 按下时间 | 按键持续按下的时间阈值（ms） |
| 作用 | 该按键触发的功能描述 |

## 输出要求

1. 文件保存到工程的 `.ai-output/` 目录下
2. 文件名为 `key_statistics.csv`
3. 编码使用 UTF-8 BOM（保证 Excel 打开中文不乱码）
4. 写入前需回到项目代码中**逐一验证**分析结果，不能靠猜测
5. 如有不确定项，在"备注"列标注，不要编造
